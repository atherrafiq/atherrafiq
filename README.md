## 📡 [FieldOps Sync](https://github.com/atherrafiq/fieldops-sync)

An offline-friendly backend for synchronizing workforce and equipment events from field applications operating under unreliable connectivity.

### Problem it explores

Mobile applications used on construction sites, vessels, remote facilities, and industrial projects may repeatedly submit the same operation after connectivity is restored.

Without idempotency, retries can create duplicate operational records.

### Engineering focus

- FastAPI backend
- Offline-first synchronization patterns
- Idempotent mobile events using `client_event_id`
- Worker and equipment management
- Equipment assignment workflow
- PostgreSQL persistence
- API-key protected endpoints
- Dockerized development environment
- Automated tests and GitHub Actions

**Tech:**  
`Python` · `FastAPI` · `SQLAlchemy` · `PostgreSQL` · `Docker` · `pytest`
